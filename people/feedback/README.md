# Feedback

Feedback runs both ways, on a quarterly rhythm — January, April, July and
October.

- **You → Cuesoft.** Everyone working with us is asked for honest feedback
  each quarter: what is working, what is broken, what you would change.
  Send it to [hello@cuesoft.io](mailto:hello@cuesoft.io) or raise it
  directly with any founder. There are no hard feelings — this is how the
  handbook and the company improve.
- **Cuesoft → you.** Structured feedback on your work comes through
  [performance reviews](../performance-review/); day-to-day feedback comes
  through code review and sprint ceremonies and should never wait for the
  quarter.
- **Anonymity.** If you prefer to give feedback anonymously, say so to a
  founder you trust and it will be handled without attribution.

If quarterly feedback surfaces something worth changing, it gets an owner
and lands in this handbook — that is the loop working.
